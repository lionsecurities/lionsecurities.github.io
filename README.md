# Lion Securities & Allied Services Website

## Files
- index.html — complete ready-to-upload website

## Run locally
Double-click `index.html` to open it in a browser.

## Publish with GitHub Pages
1. Sign in to GitHub.
2. Create a new repository named `lion-securities-website`.
3. Upload `index.html`.
4. Open Settings -> Pages.
5. Under Build and deployment, choose `Deploy from a branch`.
6. Select the `main` branch and `/ (root)`, then Save.
7. GitHub will give you a temporary `github.io` website address.

## Connect rohithnayaka.com
In GitHub Pages, add `rohithnayaka.com` as the Custom domain.
Then, at your domain provider, create DNS records pointing the domain to GitHub Pages as instructed by GitHub.
